# 한국어 교정 판단 안내

규범 판단이나 과잉 교정이 우려되는 항목만 참조한다.
아래 예문은 이 스킬을 위해 작성한 예문이다. 문맥을 생략한 자동 치환 규칙이 아니다.

## 공식 자료 선택

- [국립국어원 어문 규범](https://korean.go.kr/kornorms/regltn/regltnView.do): 한글 맞춤법, 표준어, 외래어, 로마자 표기와 문장 부호를 찾는다.
- [표준국어대사전](https://stdict.korean.go.kr/main/main.do): 표제어의 품사·뜻풀이·용례로 합성어 여부와 어휘 결합을 확인한다.
- [온라인가나다](https://www.korean.go.kr/front/onlineQna/onlineQnaList.do?mn_id=216): 규범 적용 사례를 확인한다. 질문과 공식 답변을 구별한다.
- [쉬운 공공언어 쓰기 길잡이 PDF](https://korean.go.kr/common/download.do%3Bfront%3DB2FC16C2913A23985EB8E72A00D280F7?c_file_name=901b4032-ae19-4457-87b7-e0f61c04378e.pdf&file_path=etcData&o_file_name=%E2%98%85%EC%89%AC%EC%9A%B4_%EA%B3%B5%EA%B3%B5%EC%96%B8%EC%96%B4_%EC%93%B0%EA%B8%B0_%EA%B8%B0%EB%B3%B8_%EA%B8%B8%EC%9E%A1%EC%9D%B4%28%EC%B5%9C%EC%A2%85_%EB%B0%B0%ED%8F%AC%29%EB%8B%A8%EB%A9%B4.pdf): 인쇄면 17~21쪽의 호응·어순·명사 나열·명료성 안내를 참고한다.

자료별 역할을 구별한다. 공공언어 권장은 모든 장르에 적용되는 맞춤법 조항이 아니다.
사전 수록 여부만으로 모든 문맥의 적합성을 판단하지 않는다.
자료 사이에 차이가 있으면 적용 조건과 개정 시점을 확인한다. 해결되지 않으면 차이를 밝힌다.

확인 기준일은 2026-10-07이다.
제작 당시 규범 사이트 본문은 접근 오류가 발생했다. 제43항과 제47항은 아래 공식 상담 원문으로 확인했다.
사전은 접근 경로를 확인했다. 개별 표제어를 전부 조회한 것으로 해석하지 않는다.
위 길잡이의 해당 본문은 확인했다. 책 전체를 복제하거나 규범 사전으로 사용하지 않는다.

## 띄어쓰기의 허용 범위

### 숫자와 단위

‘10개’를 무조건 ‘10 개’로 고치지 않는다.
국립국어원은 숫자와 단위 명사를 붙여 쓰는 경우도 허용한다고 설명한다.
격식체라는 이유만으로 허용 표기를 오류로 분류하지 않는다.
한글 수 표현까지 같은 규칙으로 처리하지 않는다. 일반 수량 표현인 ‘세 권’은 구분해서 판단한다.

근거: [제43항 상담 답변, 2026-08-31](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=97&pageIndex=1&qna_seq=335208).

### 보조 용언

띄어 쓰는 원칙과 붙여 쓰는 허용 범위를 함께 확인한다.
‘만들어 보다’와 ‘만들어보다’를 모두 가능한 표기로 판단한다.
합성어·파생어, 활용형과 조사 개입 여부에 따라 결과가 달라질 수 있다.
단순히 음절 수만 세거나 모든 보조 용언을 붙이는 규칙을 만들지 않는다.
사전에 한 단어로 등재된 표현인지도 필요할 때 확인한다.

근거: [제47항 상담 답변, 2026-05-11](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=331002).

### 품사와 문장 부호

‘수·지·뿐·대로·만큼’ 등은 해당 문장의 품사와 기능을 먼저 확인한다.
예: ‘할수 있다’는 ‘할 수 있다’로 고친다. ‘너만큼’과 ‘노력한 만큼’은 구별한다.
쉼표는 개수가 아니라 문장 구조와 해석에 미치는 영향으로 판단한다.
가운뎃점은 묶음·짝·공통 성분의 관계를 확인한다. 열거라는 이유만으로 모두 금지하거나 허용하지 않는다.
제목·표 항목·메신저 문구에 완결된 서술문 형식을 무조건 요구하지 않는다.

## 자연스러움의 판단

| 점검 대상 | 제안 예 | 보존할 조건 |
|---|---|---|
| 주어와 서술어의 호응 | ‘이 기능의 장점은 시간을 줄일 수 있습니다.’ → ‘이 기능의 장점은 시간을 줄일 수 있다는 점입니다.’ | 시간 절감 가능성을 확정 성과로 바꾸지 않는다. |
| 어색한 명사·동사 결합 | ‘신청 절차의 간소화를 진행했습니다.’ → ‘신청 절차를 간소화했습니다.’ | 실제로 절차를 바꿨다는 문맥일 때 제안한다. 진행 중이면 완료로 바꾸지 않는다. |
| 늘어진 구성 | ‘이 방법을 사용하는 것이 가능합니다.’ → ‘이 방법을 사용할 수 있습니다.’ | 허용·능력·가능성 가운데 원문의 의미를 유지한다. |
| 번역투 후보 | ‘이 설정에 대한 변경을 수행하세요.’ → ‘이 설정을 변경하세요.’ | 기능명이나 작업 이름으로 굳어진 표현인지 확인한다. |
| 수식 범위 | ‘오래된 친구의 사진’ | 친구와 사진 중 무엇이 오래되었는지 확인한다. |
| 정당한 피동 | ‘문이 잠겨 있어요.’ | 행위자를 새로 만들어 능동문으로 바꾸지 않는다. |
| 문맥에 맞는 사물 주어 | ‘이 표는 월별 매출을 보여 준다.’ | 사물 주어라는 이유만으로 수정하지 않는다. |
| 추정의 표현 | ‘오류가 줄어들 것으로 보인다.’ | ‘오류가 줄어든다’로 확정하지 않는다. |
| 의도적인 생략 | ‘오늘 진짜 좋았어.’ | 맥락상 자연스러운 대화에 주어·목적어를 강제로 보충하지 않는다. |

호응을 고칠 때 가장 짧은 문장이 항상 가장 적절한 문장은 아니다.
초점과 대조 의미를 보존하는 안을 선택한다.
문체상 개선이면 ‘틀렸다’보다 ‘더 간결하게 쓸 수 있다’처럼 판단의 성격을 설명한다.
원뜻을 확인해야 하는 경우에는 임의의 한 가지 수정본을 정답으로 제시하지 않는다.

## 문체별 자연스러움

사용자가 지정한 문체를 우선한다. 지정이 없으면 문서와 해당 부분의 용도를 따른다.
글머리표 안의 완결된 설명문은 서술식으로 판단할 수 있다. 혼합 문서를 하나의 문체로 강제하지 않는다.
문체가 분명하면 다시 묻지 않는다. 문체 선택이 의미나 결과 형식을 바꿀 때만 확인한다.

| 점검 대상 | 서술식 | 개조식 |
|---|---|---|
| 표현 단위 | 완결된 문장과 문단의 흐름을 확인한다. | 제목·과업·요약 항목의 핵심 내용을 확인한다. |
| 명사 중심 표현 | 행동을 동사로 풀면 뜻이 더 분명해지는지 본다. | ‘자료 검토 예정’처럼 기능에 맞는 명사형을 유지한다. |
| 주어·목적어 생략 | 앞뒤 문장에서 대상을 알 수 있는지 본다. | 상위 제목이나 공통 항목이 생략된 성분을 보완하는지 본다. |
| 연결 | 지시 대상, 대조, 인과와 정보 전환을 확인한다. | 항목 사이의 병렬·순서·조건과 계층을 확인한다. |
| 종결 | 설명·대화·인용의 말투와 시간 관계를 보존한다. | 같은 역할의 항목끼리 형식을 맞춘다. 제목과 설명을 같은 종결로 강제하지 않는다. |
| 상태와 조건 | 예정·진행·완료, 가능성·의무·추정의 차이를 유지한다. | ‘예정·중·완료·가능’ 등 의미에 필요한 표지를 유지한다. |

예: 서술식 ‘자료를 검토할 예정이다.’와 개조식 ‘자료 검토 예정’은 각각의 용도에서 자연스럽다.
‘자료 검토 중’을 ‘자료 검토 완료’로 바꾸거나, ‘승인 시 실행 가능’을 ‘실행’으로 줄이지 않는다.
원문이 명료한 개조식이면 서술식으로 늘리지 않는다. 서술식도 임의로 요약 항목으로 바꾸지 않는다.

## 한국어 구성과 번역투 후보

다음은 문맥에 따라 검토할 후보다. 단어 목록이나 자동 치환 규칙으로 쓰지 않는다.
영어식 구성과 닮았다는 관찰만으로 작성 주체나 학습 데이터의 영향을 판정하지 않는다.
문법적으로 가능하지만 용도상 어색한 표현은 원칙적으로 ‘권장’으로 구분한다.

| 점검 대상 | 판단과 제안 예 | 보존할 조건 |
|---|---|---|
| 주어 선택 | ‘이 설정은 알림 차단을 가능하게 한다.’ → ‘이 설정으로 알림을 차단할 수 있다.’처럼 도구·원인·조건 표현을 비교한다. | 사람 주어로 일괄 전환하지 않는다. ‘이 표는 월별 매출을 보여 준다.’처럼 자연스러운 사물 주어를 유지한다. |
| 생략과 지칭 | 주어·대명사의 유지, 생략, 이름·호칭으로의 대체 중 대상이 분명한 안을 선택한다. | 대상 전환·대조·재등장에는 명시가 필요할 수 있다. ‘그·그녀·그것’을 일괄 삭제하거나 불분명한 대상을 추측하지 않는다. |
| 명사 중심 서술과 어휘 결합 | 서술식 ‘위원회는 자료에 대한 검토를 진행하고 있다.’ → ‘위원회는 자료를 검토하고 있다.’처럼 실제 행동을 드러낸다. | 검토 중인 일을 완료로 바꾸지 않는다. ‘가지다·진행하다·수행하다’가 실제 소유·과정·업무를 뜻하면 유지한다. |
| 피동·사동 | 능동·피동·주어 생략 표현을 비교하고, 문장의 초점에 맞는 안을 선택한다. | 행위자 미상, 대상 강조와 상태 표현을 보존한다. 원문에 없는 행위자를 추가하거나 가능성을 확정 성과로 바꾸지 않는다. |
| 복수·시간·전치사구 | ‘여러 자료들’은 ‘여러 자료’로 줄일 수 있다. ‘~의·~에 대한·~로부터’는 관계를 드러내는 조사·동사·절과 비교한다. | 개별성·대조, 진행·완료·반복, 소유·출처와 수식 범위를 유지한다. 해당 표지가 있다는 이유만으로 삭제하지 않는다. |
| 문장 간 연결 | 연결어가 실제 인과·대조·전환과 맞는지, 지시어의 대상과 새 정보가 분명한지 확인한다. | 정확한 지칭과 강조에 필요한 반복을 유지한다. 원문의 인접 문장을 임의의 인과관계로 묶지 않는다. |
| 긴 수식과 문장 분리 | 수식어 위치를 조정하거나 문장을 나누어 읽기 부담을 줄일 수 있는지 본다. | 부정·조건·예외의 범위, 강조와 의도적인 문학적 리듬을 보존한다. 짧게 만들기 위한 정보 삭제는 피한다. |
| 호칭과 높임 | 인물 관계, 독자와 장르에 맞는 지칭과 높임을 선택한다. | 이름·직함·대명사로 바꾸면서 관계나 말투를 새로 설정하지 않는다. 관계가 불명확하면 유지하거나 확인한다. |

하나의 문장에 모든 항목을 적용하지 않는다. 실제 어색함을 설명할 수 있는 항목만 사용한다.
한국어다운 표현을 만들기 위해 감정·경험·성과를 추가하지 않는다. 자연스러운 원문에는 수정이 필요 없다고 판단한다.

### 참고 자료와 확인 범위

자료 확인일: 2026-10-14. 아래는 편집 판단의 참고 자료이며, 일괄 금지 규칙이나 맞춤법 조항이 아니다.
교수 소속은 발행 당시 기준이다. 저자가 보고한 분석 결과와 독립적인 재검증을 구분한다.
공개 본문의 관련 부분과 KCI 저자 초록을 읽은 범위를 아래에 표시했다. 논문 전체 검증이나 AI 원인 분석을 뜻하지 않는다.

- 김정우(당시 경남대학교 교수), [현대 국어 번역문의 실태](https://www.korean.go.kr/nkview/nklife/2012_1/22_0104.pdf), 『새국어생활』 22(1), 2012, 53~66쪽. 관련 본문 확인. 대명사·시간 표현·높임·접속어와 명시화의 구분을 참고한다.

문체별 표와 위 판단·예문은 자료를 참고한 이 스킬의 편집 지침이다. 자료의 직접 인용이나 규범 판정으로 제시하지 않는다.
일반적인 윤문마다 자료를 다시 검색할 필요는 없다. 출처 확인 요청이나 새로운 쟁점이 있을 때 관련 원문만 확인한다.

## 근거를 제시하는 방식

- 규범 오류: 적용되는 규정이나 실제로 확인한 사전 항목을 짧게 설명한다.
- 문법 오류: 어긋난 성분 관계를 설명한다. 규범 조항을 억지로 연결하지 않는다.
- 표현 권장: 무엇이 읽기 쉬워지는지 설명한다. 개인적 선호를 공식 규범으로 표시하지 않는다.
- 확인 불가: 확인하지 못한 항목만 밝힌다. 이미 확인한 수정까지 전부 취소하지 않는다.

출처 링크는 교정 근거에 붙인다. 조회하지 않은 홈페이지를 개별 판정의 증거로 대신 제시하지 않는다.
