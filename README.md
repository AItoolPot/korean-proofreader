# 한국어 문장 교정 · korean-proofreader

AI가 작성한 초안의 어색한 한국어 표현을 다듬는 스킬입니다.
보고서의 서술식 문장과 개조식 항목을 구분하고, 원문의 의미와 말투를 보존합니다.

ChatGPT/Codex 환경에서 제작했습니다. 대표 예문 8개에 적용해 자체 검토했고, 스킬 구조 검사도 통과했습니다.
다른 플랫폼에서의 설치·실행 여부와 교정 품질은 아직 확인하지 않았습니다.

## 이런 작업에 사용합니다

- 한국어 글의 맞춤법, 띄어쓰기, 문장 부호와 문법 점검.
- 의미는 통하지만 표현이 어색한 AI 초안의 문장 다듬기.
- 보고서, 제안서, 업무 문서의 서술식·개조식·혼합 문체 검토.
- 번역투, 명사 중심 표현, 불분명한 지칭과 문장 연결의 개선안 제시.

새 글 작성, 외국어 번역과 사실 검증만 요청한 작업은 이 스킬의 적용 범위가 아닙니다.

## 교정 기준

| 구분 | 처리 |
|---|---|
| 오류 | 표기 규범 위반이나 문맥상 분명한 문법적 결함을 최소한으로 수정합니다. |
| 권장 | 원문도 가능하지만 문맥과 용도에 더 적합한 표현을 선택적으로 제안합니다. |
| 확인 필요 | 의미나 규범을 확정하기 어려운 지점과 확인 사항을 표시합니다. |

사실·수치·조건·추정·행위자·말투를 보존합니다.
자연스러운 사물 주어와 피동문, 개조식의 명사형 표현은 유지합니다.
맞춤법만 요청하면 문체를 바꾸지 않습니다. 진단만 요청하면 전체 수정본을 만들지 않습니다.

아래는 자체 검토에 사용한 사례의 일부입니다. 문맥을 생략한 자동 치환 규칙이 아닙니다.

| 문체·점검 목적 | 원문 | 판단·수정안 |
|---|---|---|
| 서술식·명사 중심 표현 | 위원회는 자료에 대한 검토를 진행하고 있다. | 권장: 위원회는 자료를 검토하고 있다. 주체와 진행 상태를 유지합니다. |
| 서술식·사물 주어 | 이 표는 월별 매출을 보여 준다. | 유지: 문맥에서 자연스러운 사물 주어입니다. |
| 개조식·명사형 종결 | 추가 자료 검토 예정 | 유지: 과업 항목으로 자연스럽고, 예정 상태가 명확합니다. |
| 개조식·조건과 가능성 | 승인 시 실행 가능 | 유지: 승인 조건과 가능성을 보존합니다. |

## 사용 방법

이 저장소의 파일을 내려받고, 폴더 구조를 유지합니다.
스킬을 설치할 환경에서 안내하는 위치에 스킬 폴더를 넣습니다.
ChatGPT/Codex의 사용 방식은 [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)를 참고합니다.

Codex에서 스킬을 지정해 요청하는 예:

```text
$korean-proofreader
아래 글을 검토해 주세요.
원뜻과 말투를 보존하고, 오류와 선택적 문체 개선을 구분해 주세요.
개조식 항목은 개조식으로 유지해 주세요.

[검토할 글]
```

일반 채팅에서는 `SKILL.md`와 `references/language-guide.md`의 내용을 함께 제공해 교정 지침으로 참고할 수 있습니다.
이 방식의 다른 플랫폼 동작은 아직 검증하지 않았습니다.

## 제작·검증 범위

- 제작·검토 환경: ChatGPT/Codex.
- 자체 적용 검토: 대표 예문 8개. 의미·상태·문체 보존과 과잉 교정 여부를 확인했습니다.
- 구조 검사: `quick_validate.py` 통과.
- 별도 사용자 대화에서의 자동 호출, 독립 평가와 대규모 교정 정확도는 검증하지 않았습니다.
- 다른 플랫폼의 설치·실행 여부와 교정 품질은 아직 확인하지 않았습니다.

문체만으로 AI 작성 여부를 판정하거나, AI 탐지 회피 효과를 약속하지 않습니다.
참고 자료의 확인 범위는 [판단 안내](references/language-guide.md)에 기록했습니다.
